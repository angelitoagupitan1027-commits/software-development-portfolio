## Evidence Integrity Rules

1. Only record a passing result when supported by the training history.
2. Preserve the distinction between first attempts, corrections, retries, and final results when known.
3. Do not invent missing scores, dates, or code artifacts.
4. Keep practice code, assessment evidence, and official certifications distinct.
5. Add new assessment entries to this document instead of creating duplicate evidence files.
6. Update the learning progress tracker when a group or assessment status changes.

This document is a record of learning progress and practical assessments, not an official industry certification.
