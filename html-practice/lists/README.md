
# HTML Lists Practice

## Overview
This project demonstrates basic HTML list structures.

## Topics Covered
- Unordered lists using `<ul>`
- Ordered lists using `<ol>`
- List items using `<li>`
- Nested lists
- Organizing related content with HTML sections

## Learning Objective
To understand how HTML lists organize information into ordered, unordered, and hierarchical structures.
